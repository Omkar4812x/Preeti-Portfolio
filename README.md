# Preeti Chauhan Portfolio

## Overview
This is a personal portfolio website that showcases the skills, projects, and professional background of Preeti Chauhan, a software developer passionate about creating impactful digital solutions.

## Features
- **Responsive Design**: Adapts seamlessly to all devices and screen sizes.
- **Dynamic Sections**: Includes Home, About, Skills, Projects, and Contact sections.
- **Custom Animations**: Smooth scrolling and interactive background effects.
- **Interactive Features**:
  - Dynamic typing animation.
  - Tech stack and skill progress dynamically rendered.
  - Functional contact form with visual feedback.

## Technologies Used
- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript (ES6+)
- **Libraries & Tools**:
  - [Bootstrap 5](https://getbootstrap.com/)
  - [Font Awesome](https://fontawesome.com/)
  - [Vanta.js](https://www.vantajs.com/)
  - [AOS (Animate on Scroll)](https://michalsnik.github.io/aos/)

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/preeti-chauhan-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd preeti-chauhan-portfolio
   ```
3. Open `index.html` in your browser to view the portfolio.

## Deployment
This portfolio can be deployed using GitHub Pages or any static hosting platform. To deploy on GitHub Pages:
1. Commit all changes and push to the `main` branch.
2. Go to the repository settings and enable GitHub Pages.
3. Select the `main` branch as the source, and your site will be live.
